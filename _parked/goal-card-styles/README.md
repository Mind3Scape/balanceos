# Отложено: НАСТРОЙКИ ВИДА карточки цели/круга (баннер · квадрат · орбиты)

Отложено 2026-07-15 по решению David: «старое полностью заархивируй, чтобы легко
воскресить; делаешь полностью новое и стандартизированное — не важно, на какой
странице я это вижу. Настройки отображения цели на главной больше не актуальны,
они вместе с архивом в архив приезжают».

**Причина.** Карточка круга получила нить дня («Волна дня», выбор David). Пока вид
карточки оставался НАСТРОЙКОЙ, на экране одновременно жили старое и новое: где-то
орбиты, где-то квадрат без нити, где-то баннер с нитью. David назвал это кашей —
и был прав. Стандарт не может быть настройкой: либо одна карточка везде, либо
разнобой. Выбрали одну.

## Что здесь
- `goal_style_resolver.jsx` — `BOS_GOAL_STYLE_DEFAULT`, `bosLoadGoalStyle`,
  `bosSaveGoalStyle`, `useBosGoalStyle` в исходном виде (читали `bos:goalStyle`
  из localStorage, слушали событие `bos:cardStyleChanged`).
- `card_style_menu_goals_tab.jsx` — вкладка «Цели» из `CardStyleMenuLive`:
  формы баннер/квадрат + тумблеры «Орбиты вокруг цели» / «Прогресс» / «Название».

## Что осталось В ПРИЛОЖЕНИИ (ничего не удалено, воскрешение без миграций)
- `useBosGoalStyle()` **жив**, но ЗАМОРОЖЕН: всегда возвращает один стандарт
  `{ form: "banner", name: true, orbits: false, progress: true }` и больше не
  читает localStorage. Все ветки карточек (`banner`/квадрат/`orbits`) в
  `TeamTileLive` и плитке цели **на месте** — просто в стандарт попадает одна.
- `bosSaveGoalStyle` жив, `bos:goalStyle` в localStorage у пользователей не стёрт —
  если воскресить резолвер, прежний выбор человека вернётся сам.
- `GoalOrbitMini` / `GoalCardOrbit` **живы и используются** (внутри круга, «Вселенная»,
  страница «Я») — их НЕ трогали, ушёл только тумблер «орбиты на карточке».
- `CardStyleMenuLive` жив: вкладка «Привычки» и вход в «Архив» работают как раньше.
  Ушёл только сегмент-переключатель вкладок (стало одно тело — привычки).
- Стиль карточек ПРИВЫЧЕК (`bosLoadCardStyle`, `bos:cardStyle`) не тронут вообще.

## Как воскресить (5 минут)
1. `screens/live/shared_live.jsx`: вернуть тело `bosLoadGoalStyle`/`useBosGoalStyle`
   из `goal_style_resolver.jsx` вместо замороженной константы.
2. Там же в `CardStyleMenuLive`: вернуть сегмент вкладок
   `{seg(tab, [{ v: "habits", l: "Привычки" }, { v: "goals", l: "Цели" }], setTab)}`
   и обёртку `{tab === "habits" ? (…) : (…)}`, вставив тело из
   `card_style_menu_goals_tab.jsx`.
3. Пересобрать: `node scripts/build.js`. Ветки карточек уже на месте — заработает сразу.

## Чего тут НЕТ и почему
Самих карточек (`TeamTileLive`, плитка цели) здесь нет: они не отложены, а
переписаны на один стандарт. История прежнего вида — в git до v759.
